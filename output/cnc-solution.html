解法分級說明（L1 ~ L4）
  • L1 流程/制度調整 SOP、分工就能解決，不需要工具
  • L2 系統串接兩系統間手動搬資料，用 API / Webhook / Zapier / 既有軟體同步功能

對應 OP-01｜1. 報價耗時且依賴老師傅經驗 高優先
問題描述
  • 每一筆報價需資深師傅花 30–60 分鐘人工計算，無法即時回應客戶
  • 報價標準不一，同一工件不同人報出不同價格，利潤控管困難
  • 新進人員無法獨立報價，嚴重依賴 1–2 位資深人員
  • 遇到複雜幾何或特殊材質，報價時間更長且容易漏估
  • 無法快速比較不同加工方案（如：5軸 vs 3+2軸）的成本差異
解法分級
  • L4 AI 輔助：報價需讀懂 2D/3D 圖面非結構化資訊並判斷加工工序，需 LLM 視覺+推理，故屬 L4。
解決方案
  • 建立智慧報價系統（AI-Assisted Quoting）：將歷史報價資料與工件特徵（材料、尺寸、公差、數量、表面處理）訓練機器學習模型，輸入工件參數即可自動產出價格區間
  • 圖面辨識 + 工時估算引擎：上傳 2D/3D 圖檔，AI 自動辨識特徵（孔數、螺紋、公差等級、表面粗糙度），對照標準工時資料庫產出估價
  • 建立標準化報價模板：將加工成本拆解為材料費 + 機台上機時間 + 刀具耗損 + 表面處理 + 檢驗成本 + 管理費率，每一項可獨立調整
  • 建立「快速報價」與「精確報價」雙軌機制：快速報價（3 分鐘內，誤差 ±15%）用於初步接觸，精確報價（30 分鐘內，誤差 ±5%）用於正式投標

對應 OP-02｜2. 機台狀態不透明、故障後才處理 高優先
問題描述
  • 機台 OEE（設備綜合效率）要到月底結算才知道，無法即時掌握產能
  • 刀具更換全憑經驗感覺判斷，過早更換浪費刀具壽命，過晚導致不良品
  • 產能瓶頸判斷靠廠長直覺，無法用數據佐證排程瓶頸
  • 機台故障才停機維修，預防性維護幾乎沒有執行
  • 機台運轉參數（轉速、進給、振動、溫度）缺乏即時監控
解法分級
  • L2 系統串接：機台經 FOCAS / MTConnect / OPC UA 聯網擷取運轉資料，屬設備與系統的資料串接。
  • L3 規則型自動化：OEE 看板依固定公式（稼動率 × 性能率 × 良率）自動計算產出，屬規則型自動化。
  • L4 AI 輔助：刀具壽命預測需分析振動頻譜、切削電流等感測資料並判斷磨損趨勢，屬 AI 分析。合計為 L2+L3+L4 組合。
解決方案
  • 部署機台聯網監控系統（IoT + MES Lite）：透過感測器（振動、電流、溫度）或直接從 CNC 控制器（如 Fanuc FOCAS、Mazak MTConnect、Siemens OPC UA）擷取即時運轉數據
  • 建立 OEE 即時看板：將稼動率（Availability）、性能率（Performance）、良率（Quality）即時視覺化，取代月底手工統計
  • AI 刀具壽命預測：利用振動頻譜 + 切削電流數據，訓練異常偵測模型，提前預警刀具磨損，實現「換刀最佳時機」建議
  • 預防性維護排程：根據機台運轉時數與歷史故障資料，自動排入保養排程，將被動維修轉為主動保養
  • 瓶頸分析引擎：即時計算各機台在製品數量與等待時間，自動標示瓶頸機台

對應 KM-01｜3. 技術知識靠師傅口傳、人走知識也走 高優先
問題描述
  • 切削參數（轉速、進給、切深）全在老師傅腦袋裡，沒有書面紀錄
  • CNC 程式散落在個人 USB 隨身碟，無版本控制，一個 U 盤丟了全廠受災
  • 新進技術員訓練期長達 6–12 個月，嚴重影響產能與排程
  • 加工經驗無法累積，每次遇到新材料或新工件都重新摸索
  • 資深師傅退休或離職，整個技術傳承斷裂
解法分級
  • L2 系統串接：CNC 程式中央版控（Git/SVN）與切削參數知識庫屬系統化管理，搭配既有作業流程即可運作。
  • L3 規則型自動化：切削參數推薦可先以規則/查表自動產出建議，屬規則型自動化。
  • L4 AI 輔助：自然語言問答（RAG）需理解非結構化文件並生成答案，故為 L4。合計為 L2+L3+L4 組合。
解決方案
  • 建立技術知識庫（Knowledge Base）：將切削參數、工件加工經驗、刀具選型建議、材料特性等系統化記錄，結構化存放於資料庫或知識管理平台
  • CNC 程式集中管理 + 版本控制：廢止 USB 隨身碟散布方式，建立中央程式庫（Git / SVN），每次修改留有版本紀錄，可追溯到「誰、什麼時候、改了什麼」
  • AI 切削參數推薦引擎：根據材料種類、工件幾何、刀具規格、目標精度，由 AI 從歷史成功案例中推薦最佳切削參數組合
  • 建立 SOP 數位化與視覺化教學：將關鍵工序拍攝影片、製作帶有圖片的標準作業程序書，新人可透過平板即時查閱
  • 專家系統 + RAG 問答：建立「加工知識問答機器人」，員工可用自然語言提問（如：「316L 不鏽鋼钻孔用什麼轉速？」），系統從知識庫中檢索最相關的答案

對應 OP-03｜4. 排程靠白板、插單就天下大亂 中優先
問題描述
  • 排程全靠白板手寫，每次有插單就要全部重排，耗時且容易出錯
  • 無法即時掌握每台機台的負載狀態與在製品進度
  • 交期承諾不準確，業務不敢對客戶承諾確切日期
  • 缺乏「如果……會怎樣」的排程模擬能力（What-if 分析）
  • 緊急訂單與常規訂單的優先級判斷缺乏客觀依據
解法分級
  • L3 規則型自動化：APS 排程是條件固定、邏輯明確的最佳化引擎（約束條件 + 演算法），不需理解非結構化內容，不屬 LLM，故為 L3。
解決方案
  • 導入 APS（進階排程系統）或 AI 排程引擎：考慮機台能力、模具準備、人員班次、刀具更換等約束條件，自動產生最優排程
  • 即時排程看板：將排程結果視覺化於大螢幕，各機台操作員可看到自己的工單 sequence
  • 插單智能評估：當有插單需求時，系統自動計算對現有排程的影響（哪些訂單延遲、延遲多久、額外成本），提供決策依據
  • 交期預測引擎：根據目前排程負載 + 歷史加工速度，即時計算每筆訂單的預計完工日
  • 瓶頸偵測與負載平衡：自動識別過載機台，建議將工單調度至空閒機台

對應 OP-04｜5. 檢驗紀錄紙本填寫、追溯困難 中優先
問題描述
  • 檢驗紀錄全部手寫在紙本表格上，查找困難、容易遺失
  • 首件檢驗（FAI）報告與 CPK 製程能力報告製作耗時，影響出貨
  • 品質異常發生時，難以追溯是哪台機台、哪把刀具、哪個操作員、什麼參數
  • 品質數據無法即時統計分析，問題都是累積到一定程度才發現
  • 客戶要求提供品質紀錄時，需翻閱大量紙本資料，回應緩慢
解法分級
  • L2 系統串接：量測儀器數據串接至檢驗系統，屬設備與系統的資料串接。
  • L3 規則型自動化：FAI / CPK 報告依固定公式自動計算產出，屬規則型自動化。合計為 L2+L3 組合。
解決方案
  • 電子化檢驗紀錄系統：使用平板或手機進行現場檢驗紀錄，資料即時上傳雲端/資料庫，取代紙本
  • 自動化 FAI / CPK 報告生成：量測數據匯入系統後，自動計算 CPK/PPK 值、產生標準化 FAI 報告（符合 AS9102 或客戶格式）
  • 品質追溯鏈建置：每一筆檢驗紀錄綁定：訂單號、工件序號、機台、刀具、操作員、加工參數、環境溫濕度，建立完整追溯鏈
  • 即時 SPC（統計製程管制）看板：即時監控 X-bar / R Chart，當 Cp/Cpk 低於門檻值自動告警
  • AI 外觀缺陷檢測：利用機器視覺（Camera + AI 模型）自動辨識表面缺陷（刮痕、毛邊、變色），輔助人工目檢

對應 CX-01｜6. 客戶詢價等待久、進度查詢靠打電話 中優先
問題描述
  • 客戶詢價回覆需 1–3 天，期間客戶可能轉向其他供應商
  • 訂單進度查詢全靠電話，業務需打電話給廠長或現場確認，效率低落
  • 異常狀況（延遲、品質問題）被動等待發現，缺乏主動通知機制
  • 客戶無法自助查詢進度，每次都要打電話，影響滿意度
  • 多個業務同時詢問同一訂單進度，造成現場多次中斷
解法分級
  • L2 系統串接：建置線上詢價平台與客戶專屬門戶，串接 MES/ERP 訂單狀態同步，屬系統建置與資料串接。
  • L4 AI 輔助（選配）：客服問答機器人與 DFM 可行性提示需理解非結構化內容，若導入才屬 L4。
解決方案
  • 建立客戶自助查詢入口（Customer Portal）：客戶登入後可查看自己所有訂單的即時進度、預計交期、歷史紀錄
  • 自動化訂單進度同步：MES 或排程系統的工單狀態自動同步至客戶端，業務與客戶看到的是同一份即時數據
  • 異常主動通知系統：當訂單發生延遲風險、品質異常、機台故障時，自動推播通知業務與客戶
  • 智慧客服/問答機器人：處理客戶常見問題（交期、數量、出貨方式），24/7 自動回覆
  • 報價自動回覆：結合項目 1 的智慧報價系統，標準品可實現「詢價→自動報價→Email 發送」全流程

對應 DM-01｜7. 哪些訂單賺錢、哪些虧損不清楚 中優先
問題描述
  • 無法精確計算每一筆訂單的真實成本（材料 + 機時 + 人工 + 刀具 + 品管 + 管理分攤）
  • 不清楚哪個客戶、哪類工件利潤最高，資源配置缺乏依據
  • 報價與實際成本常有落差，部分訂單做越多虧越多
  • 無法區分各機台的真實貢獻度與成本效率
  • 月結報表粗糙，無法支撐精準定價策略
解法分級
  • L2 系統串接：將 MES 機台工時、ERP 材料領用與人事薪資串接成單一成本模型，屬系統間資料串接。
  • L3 規則型自動化：BI 利潤報表依固定公式自動計算毛利與成本分析，不需 AI。合計為 L2+L3 組合。
解決方案
  • 訂單成本精算系統：整合 MES 機台運轉數據（實際機時）+ 材料領用紀錄 + 刀具消耗 + 品管工時 + 管理費用分攤，精確計算每筆訂單的全成本
  • 利潤分析儀表板：依訂單 / 客戶 / 工件類型 / 機台等維度分析毛利率，找出最賺錢與最虧損的訂單特徵
  • 動態定價建議：根據歷史利潤數據 + 市場行情 + 機台空閒率，AI 建議最優報價策略（如：機台空閒時可接受較低利潤率搶單）
  • 成本異常偵測：當某筆訂單實際成本偏離預估成本超過 10% 時自動告警，及早介入
  • 客戶價值分析：識別高價值客戶（利潤貢獻高、付款準時、訂單穩定），集中資源服務

對應 RG-01｜8. 只能做低單價簡單件、無法切入高附加價值市場 中優先
問題描述

  • 缺乏精密加工能力（公差 ±0.005mm 以下、Ra 0.4 以下），無法切入醫療/航太/半導體市場
  • 不了解高附加價值市場的認證需求（ISO 13485、AS9100、NADCAP）
  • 加工精度不穩定，品質一致性不足，難以通過精密客戶的審廠
  • 缺乏先進加工技術（5軸、微細加工、超精密加工）的知識與經驗
解法分級
  • L4 AI 輔助：DFM 自動分析需判讀設計圖面等非結構化資訊並判斷製程可行性，需 LLM/視覺模型，故屬 L4。

  • AI 加工參數最佳化：利用已建立的切削參數資料庫（項目 5），結合 AI 針對高精度工件推薦最佳加工策略，提升精度穩定性
  • 製程能力分析與提升：持續監控 Cp/Cpk（項目 4），找出精度不穩定的根本原因（機台精度、刀具磨損、熱變形、夾持方式），系統性改善
  • 認證輔導與數位化準備：建立符合 ISO 13485 / AS9100 的文件管理系統（SOP + 檢驗紀錄 + 追溯鏈），AI 輔助撰寫品質手冊
  • 技術市場情報蒐集：AI 定期掃描醫療/航太/半導體零件採購需求，識別符合自身能力的切入機會
  • 建立差異化能力展示：製作精密加工案例集（含量測報告、公差實績、認證資格），作為業務推廣工具

對應 RC-01｜9. 品質追溯斷鏈、圖面外洩風險、網安漏洞 中優先
問題描述
  • 品質異常時無法追溯：不知道是哪台機台、哪把刀具、哪個操作員、什麼加工參數導致的問題
  • 客戶圖面散落在各台電腦、USB 隨身碟、個人 Email，缺乏統一管理
  • OT（營運技術）網路與 IT 網路未隔離，存在横向移動風險
  • CNC 機台多數使用 Windows XP/7 或無安全防護的嵌入式系統，容易遭受攻擊
  • USB 隨身碟隨意插拔，可能引入惡意軟體感染機台控制器
解法分級
  • L1 流程/制度：USB 禁用、圖面取用權限、資安教育訓練屬制度與分工調整，不需工具。
  • L2 系統串接：圖面集中管理（DMS）與 OT/IT 網路隔離屬系統導入與設定，不屬 LLM。
  • L3 規則型自動化：全製程追溯碼依固定規則綁定並自動產出紀錄，屬規則型自動化。合計為 L1+L2+L3 組合。
解決方案
  • 建立完整追溯鏈：每一筆產品從原料進廠到出貨，綁定：原料批號 → 機台 → 刀具 → 操作員 → 加工參數 → 品管紀錄 → 出貨紀錄（與項目 4 追溯碼系統整合）
  • 圖面集中管理 + DLP（資料防洩）：所有圖面統一存放於加密文件管理系統，控管下載/列印/分享權限，設置浮水印（含使用者資訊）
  • OT/IT 網路隔離 + 防火牆：將機台控制網路與辦公網路隔離，透過 DMZ 和工業防火牆控管跨網存取
  • 機台安全加固：升級機台作業系統（若可行）、停用不必要的 USB 埠、部署端點防護
  • 資安監控與事件回應：部署網路流量監控（IDS/IPS），建立資安事件通報與回應流程
