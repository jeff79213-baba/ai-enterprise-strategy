# 企業導入配套方案庫

本資料夾存放各行業 AI 導入項目的**詳細實施配套方案**，對應「評估問卷」中的每個可勾選選項。

## 📁 命名規則

```
{行業代碼}_{環節代碼}_{面向代碼}_{序號}_{方案簡稱}.md
```

| 代碼 | 含義 | 範例 |
|------|------|------|
| 行業代碼 | 2-4 字母 | BNB(民宿)、CNC(加工)、DEN(牙醫) |
| 環節代碼 | A/B/C/D/E... | A=行銷、B=訂房/報價、C=製造/體驗 |
| 面向代碼 | OP/CX/DM/KM/RG/RC | 營運效率/客戶體驗/決策支援/知識管理/營收成長/風控合規 |
| 序號 | 01-99 | 同一環節×面向下的第 N 個方案 |

**範例**：`BNB_C_CX_01_AI導覽小幫手.md`、`CNC_A_OP_01_AI報價引擎.md`

## 📄 配套方案標準結構

每份方案必須包含以下區塊：

```markdown
# {方案完整名稱}

> 關聯評估項目：{行業} / {環節} / {面向} / {評估項目編號}

## 1. 方案摘要
- **解決痛點**：一句話說明解決什麼問題
- **核心價值**：量化效益（如：人力 -30%、報價 10x、OEE +20%）
- **適用對象**：哪類型/規模企業適合

## 2. 詳細實施步驟
| 階段 | 任務 | 產出物 | 負責角色 | 工時估算 |
|------|------|--------|----------|----------|
| 1. 需求釐清 | ... | 需求文件 | 顧問/業主 | 4h |
| 2. 工具選型/建置 | ... | 系統帳號/環境 | 工程師 | 16h |
| 3. 資料整理/匯入 | ... | 知識庫/參數表 | 內部專家 | 8h |
| 4. 測試驗收 | ... | 測試報告 | 顧問/業主 | 4h |
| 5. 上線/移交 | ... | 操作手冊/訓練 | 全員 | 4h |

## 3. 工具/技術選型建議
| 類別 | 推薦方案 | 優點 | 缺點 | 估算成本 |
|------|----------|------|------|----------|
| 核心平台 | Dify / Coze / 自建 RAG | ... | ... | $0-5萬/月 |
| 硬體設備 | 智慧門鎖 / IoT 閘道 | ... | ... | $3萬-10萬 |
| 整合介面 | Line Bot / 網頁嵌入 / API | ... | ... | 視複雜度 |

## 4. 資料需求與前置條件
- 必備資料：歷史報價單、菜單/景點清單、刀具資料庫、SOP 文件...
- 系統前置：PMS 已上線、機台已聯網、GitLab 已建立...

## 5. 風險與對策
| 風險 | 機率 | 影響 | 緩解對策 |
|------|------|------|----------|
| 資料品質不足 | 高 | 導致 AI 回答不準 | 先做資料清洗 Sprint、設定最低門檻 |
| 員工抗拒使用 | 中 | 系統閒置 | 共創設計、高層背書、遊戲化激勵 |
| 整合介面不通 | 低 | 上線延期 | 先做 PoC 驗證 API、備援人工流程 |

## 6. 成本效益試算（3 年期）
| 項目 | Year 1 | Year 2 | Year 3 | 總計 |
|------|--------|--------|--------|------|
| 軟體授權/雲費用 | | | | |
| 硬體採購 | | | | |
| 實施人力(內部+外包) | | | | |
| 維運成本 | | | | |
| **總投入** | | | | |
| **預期效益(省時/增收/降本)** | | | | |
| **ROI** | | | | |

## 7. 驗收標準
- 功能性：[ ] 核心功能正常 [ ] 介面串接通 [ ] 多語言/多裝置相容
- 效能：[ ] 回應 < 3 秒 [ ] 可用性 99.5% [ ] 同時線上 > 50 人
- 業務：[ ] 客滿意度 +15% [ ] 人力節省 20% [ ] 轉單率 +10%
- 文件：[ ] 管理者手冊 [ ] 操作手冊 [ ] FAQ/故障排除

## 8. 後續擴充建議
- Phase 2：加入預測模型/個人化推薦/自動排程
- 整合：ERP/CRM/會計系統雙向同步
```

## 🔗 與評估問卷的對應關係

1. **評估問卷**（`{行業}AI導入評估問卷.md`）  
   → 每個可勾選選項標註 `方案代碼`（如 `BNB_C_CX_01`）

2. **配套方案**（本資料夾下的 `.md`）  
   → 檔名含相同 `方案代碼`，內容詳述實施細節

3. **客戶流程**  
   ```
   填寫問卷 → 勾選想導入項目 → 顧問彙整方案代碼 → 從本庫調取對應方案 → 組合成《導入提案書》
   ```
