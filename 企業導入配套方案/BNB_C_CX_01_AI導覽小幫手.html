配套方案：AI 導覽小幫手 + 智慧門鎖自助入住

方案代碼：BNB_C_CX_01
對應評估項目：民宿業 / C.住客體驗 / 客戶體驗 / CX-01
優先級：高優先

1. 方案摘要

解決痛點
  • 入住需等候櫃台，夜間/假日無人值守
  • 景點、餐飲、交通推薦靠口頭，不標準、多語言缺口
  • 住客偏好（枕頭、過敏、樓層）無記錄，回頭客無差異化服務
核心價值
  • 前台人力 -30%
  • 住客滿意度 ↑
  • 24/7 多語言即時回應
  • 自助入住零等待
適用對象

10 間以上、有夜間入住需求、外籍客比例 >20%、想降低前台人力成本

2. 詳細實施步驟

階段任務產出物負責角色工時估算
1. 需求釐清整理常見問答（FAQ）、景點/餐飲/交通資料、多語言術語表FAQ 文件、景點資料庫、術語表顧問/業主8h
2. 知識庫建置將 FAQ/景點/餐飲/交通/SOP 匯入 RAG 知識庫、設定檢索參數Dify/Coze 知識庫、測試問答紀錄顧問/工程師16h

4. 智慧門鎖整合採購/安裝門鎖、設定臨時密碼/臉辨/Line 通知流程、與 PMS 同步訂單門鎖系統、自動發碼流程工程師/廠商16h

3. 工具/技術選型建議

類別推薦方案優點缺點估算成本
RAG/平台Dify (雲端/自架)視覺化流程、內建 RAG、多模型、API 完整、免費額度大進階功能需自架$0-5,000/月
Coze (字節跳動)中文優化、插件豐富、免費額度高、部署簡單資料主權在海外、自訂度較低$0-3,000/月
自建完全掌控、資料不出去、可深度客製開發維運成本高開發 $10-30萬 + 維運

RemoteLock雲端管理、多平台同步、API 完整需穩定網路$3,500-7,000/把 + 訂閱

網頁聊天不綁平台、可嵌入官網、自訂 UI住客需主動開啟開發成本含在 Bot 內

4. 資料需求與前置條件

必備資料
  • 常見問答（入住/退房/設施/周邊/交通/政策）至少 50 組 Q&A
  • 景點/餐飲/體驗/交通資料（名稱、地址、電話、營業時間、特色、推薦理由、距離、照片）
  • 房型/設施/備品/政策說明（中/英/日/韓 至少雙語）
  • 歷史客服紀錄（可作為補充訓練資料）
系統前置
  • PMS 已上線且有 API/Webhook（用於訂單觸發發碼）
  • Line 官方帳號已認證
  • 穩定網路環境（門鎖若用雲端型）
人員前置
  • 一位懂業務、會整理資料的專案窗口（0.5 FTE，2 週）
  • IT 支援或外包工程師（負責 Bot 部署、門鎖 API 串接）
